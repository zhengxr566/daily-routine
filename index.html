    备份与恢复

    所有数据只存在这台设备的浏览器里，不上传到任何服务器。换手机、清除浏览器数据前，请先导出备份文件；在新设备上导入即可恢复。

    下载不方便时，也可以复制下面的文本，存到备忘录里；恢复时粘贴回来。

    手机电脑同步

    数据会存进你 GitHub 账号里的一个私密 Gist，只有你自己能看到。每台设备第一次使用时，要做下面两步：

    1. 打开 GitHub 生成令牌（要先登录 GitHub）。Expiration 选 No expiration，只勾选 gist，点页面底部的 Generate token，然后复制以 ghp_ 开头的令牌。
    2. 粘贴到下面，点「连接」。另一台设备可以用同一个令牌。

    令牌只保存在这台设备上，等同于密码，不要发给别人。

    断开只会删除这台设备上的令牌，数据仍然留在这台设备和 Gist 里。
